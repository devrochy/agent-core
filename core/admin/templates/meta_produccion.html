Checklist de promoción a producción Volver a conexiones

Dos apps, dos proyectos. Desarrollo y producción necesitan DOS apps de Meta distintas (nunca la misma app en Development Mode y Live Mode a la vez: en Development llegan los test webhooks del App Dashboard pero NO tráfico real; en Live Mode llega tráfico real pero el botón "Test" deja de funcionar -- no se puede tener ambos). Igual de importante: usá una base de datos de producción completamente separada de la de desarrollo, nunca solo un schema distinto en la misma instancia -- las credenciales de un entorno no deberían poder escribir en el otro.

No existe una API pública para disparar webhooks de test contra la app de producción. El test end-to-end automatizado se hace firmando fixtures propios con el App Secret de staging (ver scripts/replay-webhook.sh si existe en este repo, o el equivalente que uses para simular entregas).
